## Revisão degradada (sem revisor independente)

A cadeia agy -> Codex -> Grok foi tentada com o mesmo prompt e a mesma copia
descartavel do repo. As tres CLIs responderam exit 3 (indisponivel):

- agy (gemini-4-argon-high): auth/quota/rate-limit;
- Codex: auth/quota/rate-limit;
- Grok (grok-4.5): auth/quota/rate-limit.

A rede respondeu 200 para a api do GitHub no momento das tentativas, entao a
causa e autenticacao/cota das CLIs, nao conectividade. Quem implementou esta
rodada foi o proprio agente que assina este arquivo, portanto o julgamento
abaixo e auto-avaliacao, nao revisao cruzada. O ciclo nao deve ser tratado como
fechado por revisao independente ate uma dessas CLIs voltar.

Antes de gravar esta rodada, a auto-avaliacao encontrou dois checks que passavam
sem provar a afirmacao (C6 comparava so a contagem, C14 so testava empresa). Os
dois testes foram reforcados no commit 987984b e os vereditos acima refletem o
estado atual.
